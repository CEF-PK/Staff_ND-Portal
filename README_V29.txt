ND SIGNATURE UPLOAD:
Place the ND signature image in this exact location before deploying:
assets/nd-signature.png

Recommended format:
- PNG with transparent background
- Black/dark blue signature
- Approx. 600–1200 px wide
- Crop tightly around the signature

Once assets/nd-signature.png exists, every PDF report generated by the portal will automatically place it in the National Director approval/signature area. If the file is missing, the report still generates with the “National Director” signature line.
